# Log a Priori - Workflow Development Tool

**ā priōrī** (latin) = what comes first [adverb [after verb]]

A project that reveals underlying insights before they become explicit, by organizing and linking prior information.

The application is designed to track all changes made to a project across your IDE, version control tools, project management tools, web bookmarks, and Office/LibreOffice documents - covering ideas, code, and documentation updates, all encompassed in developer changelogs.
